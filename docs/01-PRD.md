# 01 · PRD（第一阶段基线）

> 来源：用户《第一阶段开发实施文档 V1.0》第 0 / 1 / 7 / 11 节
> 状态：需求基线已形成，工程实现按 Sprint 推进

## 1. 产品定义

- **一句话**：本地单人运行的跨境电商创业研究工作台，由 AI 智能体辅助完成市场、平台、选品、财务研究与知识沉淀。
- **目标用户**：准备开展跨境电商业务的个人创业者（第一阶段只有 1 个本地用户）。
- **核心问题**：研究过程分散、结论没有来源、数据不落盘、AI 调用不可控。
- **最终目标**：企业级工作台；**第一阶段只建可继续扩展的基础骨架**。

## 2. 十条开发总原则（不可违反）

1. 先工程结构，后业务功能
2. 先数据库与基础架构，后复杂 Agent
3. 先单人本地，后云端企业部署
4. 先打通一条完整业务流程，后扩展模块
5. 所有数据持久化，不能只存在前端页面
6. 所有功能真实可用，静态页面不冒充功能
7. AI 必须通过受控接口调用工具
8. 所有重要操作留日志
9. 数据库变更必须通过迁移文件
10. 所有开发工作有测试与验收记录

## 3. 第一阶段范围

### 3.1 P0 基础模块（文档 1.1）

基础工程、综合首页、AI 总管家、Agent 中心、项目中心、任务中心、工作流中心、市场研究、
平台比较、选品研究、供应链研究、财务模拟、学习中心、成长档案、知识库、文件中心、
报告中心、数据溯源、安全中心。

> 注意：这是**第一阶段整体范围**，不是 Sprint 1 范围。Sprint 1 只交付其中「基础工程 + 综合首页 + 导航 + 数据库连接」。

### 3.2 只预留接口、不实现（文档 1.2）

真实多平台店铺管理、订单与库存同步、自动商品发布、自动广告投放、真实客户客服、
自动退款与采购、企业组织管理、完整 SaaS 多租户、插件市场、复杂商业仿真、企业级财务自动化。

导航中一律标记「规划中」，不得让用户误以为可用。

## 4. 用户只做五件事

说清目标 → 看可点的界面说对/不对 → 上线前试关键流程 → 确认钱/隐私/不可逆三件风险 → 看人话说明书签字。
