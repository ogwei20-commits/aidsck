# 07 · UI 设计契约

> 来源：文档第 7 节 + 本团设计手艺规范。当前只交付综合首页与导航。

## 1. 主张（一句话）

**这是一个掌控台，首屏回答「此刻该处理什么」。**
所以首屏主角不是三张卡片、不是大标题海报，而是**一个可交互的任务输入框 + 一个来自数据库的真实大数字**；
其余信息全部降级为状态、列表与表格。

## 2. 设计 Token

```yaml
底色:    paper #FBFAF7 / surface #FFFFFF / surface-2 #F2F0E9
通栏带:  band #161A1F（非纯黑）/ band-2 #232A31
文字:    ink #12100E / text #26241F / muted #6B675E
边线:    line #E3DFD5
强调色:  accent #0B6E7A（唯一高彩度色，面积 ≤5%）
语义色:  info #2C6ECB / warn #B26A00 / danger #B3261E / ok #2E6B4F
字号:    12 / 13 / 15 / 18 / 24 / 30 / 48 / 64（只准这八档）
间距:    4 的倍数；节间 72 与 112 交替
字体:    Inter / PingFang SC / Microsoft YaHei / Noto Sans CJK SC（本地字体栈，不联网）
数字:    等宽字体
图标:    内联 SVG 图标库，16/20/24px，禁 emoji
```

明度层级 ≥2 级：浅底 + 一条通栏深色带。标题与正文比例 ≥3 倍（48 / 15）。

## 3. 逐节编排（版式不重复）

| 节 | 版式 | 内容 |
|---|---|---|
| 首屏 | **满幅深色带** | 主张标题 + 一个输入框 + 一个按钮 + 右侧 64px 真实数字 |
| 01 | **分栏** | 当前项目 / 今日任务（两栏，真实数据 + 创建表单） |
| 02 | **表格** | 最近操作日志（时间/动作/对象/权限/详情） |
| 03 | **提示条** | AI 未配置 + 规划中模块不可用的诚实提醒 |
| 04 | **列表** | 19 个模块交付状态，逐项标 Sprint |
| 05 | **图示/引用** | R/E/P/S/U 数据类型阶梯（内联 SVG，有信息，非灰块） |

## 4. 两处「根据这个需求定的决定」（不是换色换字体）

1. **首屏把输入框当主角**：这产品是"查与掌控"，不是营销落地页。眼睛第一落点是"我要做什么"，
   大数字只是它的注脚。
2. **模块状态用路线图列表而非卡片网格**：19 个模块里 16 个是规划中，必须让"不可用"一眼可见，
   卡片网格会把不可用和已可用拍平成一样大，属于误导。

## 5. 五条自检

- 一眼知道这是什么 ✅ 首屏标题 + 品牌
- 先看的东西最该先被看到 ✅ 一屏一个主角
- 看得出层级 ✅ 八档字号 + 两级底色 + 通栏深色带
- 不像模板 ✅ 五节五种版式，换成别家名字不成立
- 宽屏不空 / 手机不挤 / 键盘能走完 ✅ 1080 与 640 两档断点，表单可键盘提交

## 6. 状态与边界

- 数据库未连通：显示空状态 + 红色配置横幅，**不伪造数据**
- 空列表：真实空状态文案，不用灰块占位
- 规划中模块：只有占位页 + 明确「尚未开发」横幅
- 动效仅 3 处（按钮 hover、导航过渡、章节入场），`prefers-reduced-motion` 降级为 none
