# 07 · UI 设计契约（v2）

> 来源：文档第 7 节 + V2 重做结论（见 `REDESIGN-V2.md`）。
> v1 的「浅色 + 通栏深色带」版式已被 v2 取代；本文件描述当前实际实现，不是设想。

## 1. 主张

**这是一个掌控台：首屏回答「此刻该处理什么」。**

首屏主角是**一个可交互的目标输入框**与**一个来自数据库的真实数字**，不是卡片墙、不是海报式大标题。
其余信息降级为状态、列表与表格。判断标准：删掉任何一块，用户是否还能完成"输入目标 → 看结果 → 确认"。

## 2. 主题与 Token

三套配色共用同一套语义变量名，切换只换值（`src/app/globals.css` 中 `[data-theme="..."]`）。
选择写入 cookie，刷新不丢；默认 **dark**。

| 方案 | 定位 | 关键色 |
|---|---|---|
| `dark` 深色专业（默认） | 信息密度高、长时间看不累、AI 工具感 | paper `#0d1117` / accent `#4a9eff` |
| `amber` 浅色琥珀 | 贸易、物流、钱的味道 | paper `#fdfbf7` / accent `#b45309` |
| `indigo` 浅色靛蓝 | 稳重企业感，报告与数据为主 | paper `#ffffff` / accent `#4338ca` |

语义变量（组件只能用这些，禁止硬编码色值）：

```
paper / surface / surface-2 / band / band-2
ink / text / muted
line / line-strong
accent / accent-ink / accent-soft
ok / warn / danger / info
side-bg / side-text / side-heading / side-hover / side-active-bg / side-active-text / side-line
shadow
```

字号只用八档：`12 / 13 / 15 / 18 / 24 / 30 / 48 / 64`。金额与数字用等宽字体。
图标全部内联 SVG（`src/components/ui/icons.tsx`），禁 emoji、不引图标包。

## 3. 页面骨架

### 3.1 通用模块页（19 个模块共用）

```
页头：分组 / 模块名 · 一句话说明 · 右侧计数
01  新建表单（或上传控件）
02  专属区块（仅部分模块：项目里程碑 / 财务结果）
03  记录列表：工具栏（搜索 + 结果计数 + 页码窗口）+ 表格
04  专属区块（仅报告：导出 / 来源）
```

- 页头计数是**服务端总数**，搜索时显示"条匹配"
- 表单提交后立即刷新列表，不弹 toast 假装成功
- 表格为空时给真实空状态文案，搜索无结果时提示换关键词

### 3.2 特殊页面

| 页面 | 版式 | 关键交互 |
|---|---|---|
| 综合首页 | 首屏输入 → 驾驶舱四数字 → 双栏（任务/学习）→ 最近执行 → Agent → 沉淀 → 边界 | 首屏提交建任务；最近执行可展开全文并就地「确认完成」 |
| AI 总管家 | 大输入框 + 项目下拉 + 派发勾选 → 结果区（调度摘要 + 分步状态） | 勾选后逐条派发，每步显示「已跑完 / 执行失败 / 需人工」 |
| 工作流中心 | 流程卡片 + 最近运行时间线 | 启动、推进、闸门批准/驳回、失败节点重试/跳过 |
| 执行记录 | 统计条 → 筛选（Tab + 搜索 + 状态下拉 + Agent 下拉）→ 日期分段列表 → 分页 | 行展开读输入与产出全文，可复制产出 |
| 报告页 | 列表 → 导出区 → 来源面板 | 导出 .md / 打印；来源登记与删除 |
| 项目页 | 列表 → 里程碑看板（分组进度条） | 加节点、勾完成、删除、逾期标红 |

## 5. 响应式

| 断点 | 变化 |
|---|---|
| ≤1180px | 首页双栏收窄，侧栏保持 |
| ≤1000px | 侧栏变顶部汉堡 + 抽屉；19 项纵向可滚 |
| ≤860px | 表单纵向堆叠；里程碑进度条隐藏、改为数字；来源条目改两列 |
| ≤640px | 字号与内边距收紧；表格横向滚动容器内滚动，不撑破页面 |

硬指标：**375 / 834 / 1440 三档无横向溢出**（实测 20 页 × 3 档，溢出 0）。
所有表单控件显式 `width:100%` + `min-width:0`，避免 `select` 被最长 option 撑开。

## 6. 状态与边界

| 状态 | 处理 |
|---|---|
| 数据库未连通 | 页面外壳保留，显示红色横幅 + 人话原因 + 修复路径；**不伪造数据** |
| 渲染异常 | 路由错误页：错误信息、错误指纹、重试、排查顺序 |
| 根布局异常 | 全局错误页：内联样式，不依赖样式表 |
| 空列表 | 真实空状态文案 + 下一步入口 |
| 搜索无结果 | 提示换关键词，保留搜索框内容 |
| 提交失败 | 表单下方就地显示错误，字段级提示来自 422 响应 |
| 执行中 | 按钮禁用 + 文案变化（「拆解并派发中…」） |

## 7. 可访问性

- 所有可聚焦元素有 `:focus-visible` 外框
- 抽屉关闭时 `inert`，Tab 不进入；`aria-expanded` 同步
- 里程碑勾选用 `role="checkbox"` + `aria-checked`
- 筛选用 `role="tablist"` / `aria-selected`；当前页用 `aria-current="page"`
- 图标按钮均有 `aria-label`
- `prefers-reduced-motion` 下关闭过渡
