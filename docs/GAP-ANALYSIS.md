**先做 P1 的财务多售价情景对比**。这是蓝图 7.6 明确点名、当前唯一算「功能缺失」而非「体验缺失」的一项：单方案能算，但"卖 129 / 149 / 169 分别是什么结果"还没法一次看完。纯计算、无外部依赖，改动集中在 `finance.ts` 与一个结果视图。
