## 五、下一步建议

**本地联网使用所需的 P0/P1 已清空。** 剩下的按「上公网前必须做」和「长期质量」两块排：

1. **登录与多用户隔离**。现在固定单用户（`APP_USER_ID`），所有查询靠 `user_id` 过滤但没人校验身份。
   局域网自用可以，**上公网前必须先做**。
2. **CI**。仓库已推送，但测试还没在提交时自动跑。有了 CI 才能保证「这次真的没坏」。
3. **工作流定时/触发运行**。现在只能手动推进，缺任务队列。
4. **汇率换算入口**。`currency_rates` 表已建，页面还没有换算能力。
5. **接入真实模型**。需要先明确预算与 Provider；接入后同步执行要改成后台队列。
